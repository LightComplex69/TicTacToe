# TicTacToe
A Tic-Tac-Toe style game for android devices.
## Description
This game follows the basic rules of Tic-Tac-Toe, but adds a twist by including the ability for a variable number of board sizes and rules that adjust accordingly. It also features 2 types of board logic: a 2D array and a HashMap.
* currently only includes working backend game logic; there is no interactive UI
## Background
This was made in the CS 4518 course at WPI.
